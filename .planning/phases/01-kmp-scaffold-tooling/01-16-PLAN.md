<objective>
Close BI-F: migrate all KMP library modules (`:shared-core`, `:shared-components`, `:shared-app`) and `:androidApp` to the AGP 9 KMP DSL so `./gradlew :androidApp:assembleDebug` exits 0. This is the gate that unblocks plan 01-15 Task 3 (Android smoke) and plan 01-14 (Android smoke + iOS HUMAN-UAT).

Purpose: AGP 9.0+ deprecated the legacy `com.android.library` integration with `kotlin.multiplatform`. The pre-AGP-9 shape — `kotlin { androidTarget() }` plus a top-level `android { namespace; defaultConfig; compileOptions }` block — fails compilation under AGP 9.2.0 with `Unresolved reference: defaultConfig / compileOptions / sourceCompatibility / targetCompatibility`. The new shape moves the Android configuration inside the `kotlin {}` extension as `androidLibrary { … }` (or `android { … }` on AGP ≥ 8.12.0; both are accepted on 9.2.0, `androidLibrary` is stable through AGP 9.x). For `:androidApp`, AGP 9's built-in Kotlin and new Application DSL are incompatible with `kotlin.multiplatform` applied to a `com.android.application` module — so the KMP plugin is removed and built-in Kotlin handles compilation.

Output: Three migrated library modules, one simplified app module, BI-E bypass flags removed from gradle.properties, Android smoke green, 01-HUMAN-UAT.md updated.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pre-AGP-9 DSL → AGP 9 KMP DSL | The `android { … }` block moved from a top-level extension provided by `com.android.library` to a configuration block inside `KotlinMultiplatformExtension`. The values (namespace, compileSdk, minSdk, jvmTarget) cross this boundary in their entirety; a typo or omission silently changes module identity or build target |
| `kotlin.multiplatform` plugin → AGP 9 built-in Kotlin (androidApp) | Compilation of `:androidApp` Kotlin sources transfers from the JetBrains KMP toolchain to AGP's built-in Kotlin compiler. Both are based on the same Kotlin compiler version (2.3.21), but configuration paths differ |
| BI-E bypass flags removal | `gradle.properties` flags that enabled BI-E "temporary bypass" are reverted; if Task 4 doesn't fully drop `kotlin.multiplatform` from `:androidApp` first, removing the flags will re-trigger BI-E |
| commonTest → Android Library Plugin host test surface | `withHostTestBuilder {}` registers JVM-host commonTest under the new plugin. Without it, commonTest sources compile but no test task is wired, so test failures become silent passes |
