```toml
# Kotest assertions (commonTest — assertions only, NOT the Kotest engine)

# KMMBridge
# (plugin only — no library artifact)

# vanniktech maven-publish
# (plugin only — no library artifact)
```

Then add `[plugins]` section — copy from STACK.md Section 12. Replace the `android-library` alias (which would use `com.android.library`) with `android-kmp-library` pointing to `com.android.kotlin.multiplatform.library`, same agp version:

```toml
android-kmp-library   = { id = "com.android.kotlin.multiplatform.library", version.ref = "agp" }
```

Keep `android-application` (for `:androidApp`) and REMOVE the plain `android-library` alias entirely — it must never appear in this project (Pitfall 20, D-14).

IMPORTANT: do NOT add a `kotest` library alias that references the Kotest test engine — only `kotest-assertions-core` is permitted (STACK.md §8, PITFALLS.md).
